# Ethical reflection

Prompt Coach gives AI feedback to beginner students, so a confident but incorrect suggestion could teach the wrong prompting habit or make a student doubt a reasonable draft. The interface therefore calls the response “AI guidance, not a grade,” keeps the four criteria visible and asks the learner to use their own judgment. A next step is to test the wording with students and a teacher, record recurring errors and revise the coach instructions when the same problem appears repeatedly.

The learner’s goal and prompt leave the browser and are sent to an AI service. A student could accidentally include a name, student number, private situation or confidential coursework. The input screen warns learners to leave out personal and confidential information, and the prototype has no account or in-app history. That does not prove that the external AI provider retains nothing. A production version should link to a clear retention policy, minimise logged data and offer a deletion route.

The tool could also support academic misconduct if someone uses the feedback to improve a request for prohibited work. Prompt Coach reduces this risk in three places: its system instruction says to coach the prompt instead of completing the assignment, its examples ask for explanations and practice, and the learner must write the revision rather than receiving a pre-filled answer. The interface also reminds users to follow course rules and disclose AI help where required. Future testing should include misuse prompts and a teacher review of the refusal boundaries.

Access is another risk. The current prototype requires internet access, a connected device, English reading ability and some confidence with AI interfaces. Those requirements may exclude learners with limited connectivity, other language needs or accessibility incompatibilities. The current version uses semantic labels, keyboard-accessible controls, responsive layouts, live status announcements and reduced-motion support. These features still need testing with screen readers and real users. Later versions should add plain-language translations and an offline worksheet that teaches the same four prompt dimensions.
