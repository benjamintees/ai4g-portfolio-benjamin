# Prompt Coach demo

[Watch the 57-second complete screen recording](prompt-coach-screen-demo.webm)

The screen recording captures the complete example flow in the connected Lovable preview on 10 September 2026. On-screen labels explain every stage while the recording shows the real interface actions and live AI responses:

1. The learner enters “Understand Python while loops” and the draft “Help me learn Python.”
2. The live Lovable AI service evaluates Goal, Context, Constraints and Output and returns feedback about the submitted wording.
3. The coach’s example revision is opened and shown in full as one possible improved prompt.
4. The learner writes a separate revision in their own words.
5. The live service compares both versions and returns specific improvements plus one next step.

The recording shows the working product, not a wireframe or static design mock-up. The product source and server-side Lovable AI integration are in [`../prompt-coach/`](../prompt-coach/).
